> **Facebook Tool Pro** là giải pháp phần mềm all-in-one cao cấp dành cho nhà sáng tạo nội dung, doanh nghiệp và agency. Hỗ trợ sáng tạo bài viết cùng **Google Gemini AI**, lên lịch đăng bài thông minh, nhập lịch hàng loạt từ **Excel** với tính năng xem/sửa/chọn bài trước khi đăng, và quản lý hàng chục Fanpage cùng lúc.

---

## 🌟 Tính Năng Nổi Bật

### 1. 🤖 AI Studio - Trợ Lý Sáng Tạo Nội Dung Thông Minh
* **Tích hợp sẵn Google Gemini AI:** Hỗ trợ các mô hình mới nhất (`gemini-3.5-flash-lite`, `gemini-3.1-flash-lite`, `gemini-3.6-flash`) với tốc độ phản hồi cực nhanh.
* **Đa dạng nhà cung cấp:** Hỗ trợ thêm OpenAI (ChatGPT), DeepSeek, Groq (Llama 3.3) và Custom Agent Endpoint.
* **Gợi ý Prompt 1-Click:**
  * 🎯 Viết bài bán hàng khuyến mãi theo công thức **AIDA**.
  * 🎬 Kịch bản video ngắn Facebook Reels 30 giây giữ chân người xem.
  * 🏷️ 15 Hashtag thịnh hành tiếp cận khách hàng tiềm năng.
  * 💬 5 Kịch bản bình luận Seeding kéo tương tác tự nhiên.
  * 📅 Lập kế hoạch nội dung Fanpage 7 ngày tự động.
* **Chuyển giao tức thì:** Nút **"Đưa vào bài viết mới"** tự động chuyển nội dung AI vừa viết sang khung soạn thảo đăng bài.

### 2. 📊 Nhập Lịch Đăng Hàng Loạt Từ Excel (Bulk Upload)
* **Kéo thả tệp Excel:** Hỗ trợ đọc các định dạng `.xlsx`, `.xls` và cung cấp sẵn file mẫu chuẩn.
* **Duyệt bài trước khi xuất bản (Staging):**
  * Danh sách bài đăng sau khi đọc sẽ hiển thị rõ ràng trên giao diện.
  * Hỗ trợ **Xem trước**, **Chỉnh sửa nội dung / ngày giờ đăng** hoặc **Xóa bài** không mong muốn.
  * **Tick chọn từng bài** hoặc **Chọn tất cả** để quyết định chính xác bài nào sẽ được lên lịch.
* **Lưu lịch sử tệp đã tải:** Tự động lưu lại các tệp Excel đã upload để bạn có thể mở lại nạp dữ liệu bất cứ lúc nào mà không cần tải lại file.

### 3. ✍️ Soạn Thảo & Tùy Biến Bài Đăng Facebook Chuyên Nghiệp
* **Bộ đổi phông chữ Facebook độc đáo:** In đậm, in nghiêng, gạch chân, chữ bong bóng nghệ thuật (Unicode hiển thị trực tiếp trên Newsfeed Facebook).
* **Bộ chọn giờ 24 Giờ chuẩn xác:** Trực quan từ `00:00` đến `23:59`, tự động định dạng chuẩn múi giờ Việt Nam.
* **Xem trước trực tiếp (Live Facebook Feed Preview):** Hiển thị mô phỏng y hệt giao diện Facebook thật cả trên máy tính lẫn điện thoại.
* **Bình luận tự động (Auto Seeding Comments):** Thiết lập trước các bình luận mồi kèm thời gian delay tự động xuất hiện dưới bài đăng.

### 4. 📅 Lịch Xuất Bản 7 Cột Trực Quan (Interactive Calendar)
* Lưới lịch chuẩn 7 ngày trong tuần từ **Thứ 2 đến Chủ nhật**.
* Đánh dấu ngày hiện tại với huy hiệu phát sáng nổi bật.
* Phân loại màu sự kiện:
  * 🟢 **Đã xuất bản (`Published`):** Màu xanh lá an toàn.
  * 🔵 **Chờ xuất bản (`Pending`):** Màu xanh dương dịu mắt.
  * 🔴 **Lỗi đăng bài (`Failed`):** Màu đỏ cảnh báo.
* **Modal xem nhanh:** Bấm vào bất kỳ sự kiện nào trên lịch để xem ngay nội dung chi tiết bài đăng và Fanpage tương ứng.

### 5. 👥 Quản Lý Đa Kênh Fanpage & Đăng Nhập Linh Hoạt
* **Đồng bộ tự động từ Facebook:** Kết nối qua Meta Graph API để lấy toàn bộ danh sách Fanpage bạn đang quản trị.
* **Đăng nhập Nhanh (Direct Login):** Vào làm việc ngay lập tức bằng Tên & Facebook UID mà không cần tạo ứng dụng Facebook Developers phức tạp.
* **Đăng nhập qua Token cá nhân hoặc OAuth 2.0 chuẩn Meta.**
* **Menu tài khoản Topbar & Cài đặt chuyên sâu:** Quản lý cấu hình API Key AI, Meta App, thông tin cá nhân và thông báo hệ thống.

## 🖥️ Yêu Cầu Hệ Thống

* **Hệ điều hành:** Windows 10/11, macOS hoặc Linux.
* **Node.js:** Phiên bản 18.x hoặc 20.x trở lên.
* **Redis Server:** Dùng cho hàng đợi BullMQ (Cổng mặc định `6379`).
* **Cơ sở dữ liệu:** Microsoft SQL Server (hoặc Docker SQL Server).

## ⚡ Hướng Dẫn Cài Đặt & Chạy Ứng Dụng

### Bước 1: Tải mã nguồn về máy
```bash
git clone https://github.com/Lovanlong1210/facebook-tool.git
cd facebook-tool
```

### Bước 2: Cài đặt thư viện phụ thuộc

Mở Terminal tại thư mục `facebook-tool` và cài đặt cho cả Client và Server:

```bash
# Cài đặt thư viện cho Backend
cd server
npm install

# Cài đặt thư viện cho Frontend
cd ../client
npm install
cd ..
```

### Bước 3: Cấu hình tệp môi trường (.env)

Trong thư mục `server/`, tạo tệp `.env` (hoặc copy từ `.env.example`):

```env
# Cổng ứng dụng
PORT=5000
CLIENT_ORIGIN=http://localhost:3000

# Cơ sở dữ liệu SQL Server
DB_USER=sa
DB_PASSWORD=your_sql_password
DB_SERVER=localhost
DB_NAME=FacebookWorkspace
DB_PORT=1433

# Máy chủ Hàng đợi Redis
REDIS_HOST=127.0.0.1
REDIS_PORT=6379

# Khóa phiên làm việc
SESSION_SECRET=your_random_session_secret_32_chars
COOKIE_SECURE=false

# Cấu hình Meta Facebook App (Nếu dùng OAuth)
FACEBOOK_APP_ID=your_facebook_app_id
FACEBOOK_APP_SECRET=your_facebook_app_secret
FACEBOOK_REDIRECT_URI=http://localhost:5000/api/auth/facebook/callback

# Cấu hình AI Studio (Google Gemini AI - Miễn phí)
GEMINI_API_KEY=your_gemini_api_key_here
GEMINI_MODEL=gemini-3.5-flash-lite
```

> 💡 **Mẹo lấy API Key Gemini miễn phí:** Bạn chỉ cần truy cập [Google AI Studio](https://aistudio.google.com/app/apikey), bấm **"Create API Key"** và dán vào mục `GEMINI_API_KEY`.

---

### Bước 4: Khởi chạy ứng dụng

#### 👉 Cách 1: Khởi chạy 1-Click trên Windows (Khuyên dùng)
Bấm đúp chuột vào tệp:
* **`start.bat`**: Tự động mở cả Backend (`http://localhost:5000`) và Frontend (`http://localhost:3000`).
* **`stop.bat`**: Đóng toàn bộ các dịch vụ đang chạy nền khi dừng làm việc.

#### 👉 Cách 2: Khởi chạy bằng dòng lệnh thủ công
Mở 2 cửa sổ Terminal riêng biệt:

* **Cửa sổ 1 (Khởi động Server):**
  ```bash
  cd server
  npm run dev
  ```
  *(Server sẽ lắng nghe tại `http://localhost:5000`)*

* **Cửa sổ 2 (Khởi động Giao diện Next.js):**
  ```bash
  cd client
  npm run dev
  # hoặc chạy bản production:
  # npm run build && npm run start
  ```
  *(Giao diện sẽ chạy tại `http://localhost:3000`)*

## 📖 Hướng Dẫn Sử Dụng Nhanh

1. **Đăng nhập:**
   * Mở trình duyệt vào `http://localhost:3000`.
   * Chọn tab **"Đăng nhập Nhanh"** ➔ Nhập tên của bạn và Facebook UID bất kỳ ➔ Bấm **"Đăng nhập ngay"**.
2. **Sáng tạo bài viết với AI:**
   * Bấm vào menu **"AI Studio"** ở thanh điều hướng bên trái.
   * Chọn một câu lệnh mẫu (ví dụ: *Bài bán hàng khuyến mãi*) hoặc nhập yêu cầu riêng của bạn.
   * Nhấn **"Đưa vào bài viết mới"** để chuyển văn bản sang khung soạn thảo.
3. **Lên lịch đăng bài:**
   * Tại trang **"Viết bài"**, chọn Fanpage muốn đăng.
   * Chọn hình thức: **Đăng ngay lập tức** hoặc **Lên lịch hẹn giờ (24h)**.
   * Bấm **Xuất bản** để đưa bài viết vào hàng đợi BullMQ tự động.
4. **Nhập lịch từ Excel:**
   * Chọn menu **"Thêm / Tải Excel"**.
   * Bấm tải file mẫu Excel, điền danh sách bài đăng rồi kéo thả vào ô upload.
   * Xem lại danh sách, chỉnh sửa nội dung nếu cần, tick chọn các bài muốn đăng và bấm **"Xác nhận & Lên lịch"**.
5. **Theo dõi trên Lịch biểu:**
   * Bấm menu **"Lịch đăng"** để kiểm tra lịch xuất bản theo từng ngày trong tháng.

│   │   │   ├── channels/       # Quản lý kênh Fanpage
│   │   │   ├── post-planner/   # Soạn bài, Lịch đăng, Tải Excel, Danh sách
│   │   │   ├── settings/       # Cài đặt hệ thống & Tài khoản
│   │   │   ├── dashboard.jsx   # Bảng tin tổng quan
│   │   │   └── login.jsx       # Trang đăng nhập đa phương thức
│   │   ├── services/           # Kết nối API (postApi, channelApi, aiApi, authApi)
│   │   └── styles/
│   │       └── globals.css     # Design System & Micro-animations toàn diện
├── server/                     # Mã nguồn máy chủ Node.js / Express (Backend)
│   ├── src/
│   │   ├── config/             # Cấu hình CSDL, Redis, Meta App
│   │   ├── controllers/        # Bộ điều khiển xử lý logic
│   │   ├── queues/             # Hàng đợi xuất bản tự động BullMQ
│   │   ├── routes/             # Định tuyến API
│   │   ├── services/           # Xử lý Graph API, Gemini AI, Excel
